## 🚀 How to Deploy on GitHub Pages (Free 1-Click Hosting)
1. Go to this repository on GitHub: `https://github.com/Ninaad783/chetan-travel-site`
2. Click **Settings** (tab at the top right of the repository).
3. In the left sidebar, click **Pages**.
4. Under **Build and deployment** > **Branch**:
   - Select `main`
   - Folder: `/ (root)`
5. Click **Save**.
6. Wait 1-2 minutes — your live website URL will appear at:
   `https://ninaad783.github.io/chetan-travel-site/`
